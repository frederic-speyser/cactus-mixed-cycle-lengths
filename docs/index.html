cactus-mixed-cycle-lengths — companion page

Counting cacti built
from more than one cycle length

Companion illustrations for the article "Enumeration and Asymptotic Analysis of Strict Non-Plane Cactus Graphs over a Finite Set of Cycle Lengths" — every cycle in the graph must have a length drawn from a fixed finite set Ω, fixed in advance. This page shows what that produces: four worked examples, how fast each one grows, and eight integer sequences drafted from the code for OEIS.

Four examples, one obstruction

Reproduced with reproduce_table1.py at its default (modest) precision — within the tolerance documented in that script of the article's published Table 1.

The growth rate 1/ρΩ always has a well-defined value. Whether it has a closed form — an exact algebraic expression, rather than only a number computed to some precision — depends on parity: every length in Ω odd gives one (Theorem 5); one even length blocks the method that produces it (Proposition 6).

“Exceptional n” lists the vertex counts where the rooted series has a provably zero coefficient (Theorem 3 / Corollary 4) — not missing data, an exact consequence of which totals a chain of blocks of these lengths can and can't reach.

How fast do they grow

Rooted count, indexed by number of blocks k = 1…25 — computed with mgonal_cactus_series_omega_blocks.py.

Plotted on a log scale, so the slope you see is the growth rate: a steeper line means more graphs per added block. All four curves are real computed values, not illustrative — every point below is a term from the sequences drafted for OEIS.

Eight sequences, drafted for OEIS

One rooted and one unrooted count for each of the four Ω above. They extend an existing OEIS table (A332648 / A332649) that already carries single-length columns for this family, into the mixed-Ω case it doesn't yet cover — and a manual search on 2026-08-26 found no existing match for any of the eight.
